Profil & Fokus Pengembangan

Saya adalah seorang Software Engineer yang memiliki keahlian mendalam pada pengembangan aplikasi Android native (Kotlin & Java) dan arsitektur sistem backend berbasis PHP / Laravel RESTful API.

Di lingkungan Universitas Semarang (USM), saya bertanggung jawab merancang dan memelihara ekosistem aplikasi penting seperti Aplikasi USM SIMA (Portal Akademik Mahasiswa/Dosen), USM Presensi & Kinerja Doskar (Sistem Presensi Geofencing GPS), Aplikasi USM Eksekutif (Executive Dashboard Rektorat), serta sistem Tracer Study Backend API.

Saya juga berpengalaman menangani proyek aplikasi instansi publik seperti presensi lapangan Dinas Pekerjaan Umum (DPU), portal event Acarain, dan aplikasi showcase UMKM Made in Blora.
